# Software Overview

The software is built around ROS 2, and this GitHub repo is meant to be cloned into a ROS 2 workspace (the `src/` folder).
All packages are also ROS 2 packages, containing nodes that handles a specific task. 

There are five overall categories of packages:

- Bringup 
  - Contains lots of launch files that implements different behaviours/modes, like face following or teleoperation. 
  - See the `energirobotter_bringup` package

- Interfaces
  - Custom ROS message types.
  - See the `energirobotter_interfaces` package

- Descriptions
  - Robot URFD description of robot platforms.

- Control

- Teleoperation

- Vision
